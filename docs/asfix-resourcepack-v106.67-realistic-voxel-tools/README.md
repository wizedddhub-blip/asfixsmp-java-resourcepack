## Tool models
13 custom handheld models for the Miner, Farmer, Slayer and Woodcutter jobs plus three Miner pickaxe tiers and Astral, Infernal and Nebula weapons. Each model uses native Minecraft item cuboids for volume, shaped heads, metal bevels, wrapped handles, fittings, and set-specific silhouette details. Their geometry report lists 1,177 cuboids across 13 distinct model shapes.

The pack uses 13 natural-material textures at 64×64: forged iron, cold steel, dark iron, aged bronze, warm brass, oak, walnut, leather, and five gem materials. Purple is limited to amethyst weapon accents.

## HUD
The archive contains custom BetterHud font JSON and PNG image assets. BetterHud plugin YAML, Oxanium/Silkscreen font files, and the HUD layout remain server-side under plugins/BetterHud; those are not embedded as client YAML in this ZIP. The HUD image preview is the separate v106.60-hud-bois-bronze-jade.png file.
